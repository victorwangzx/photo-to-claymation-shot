# Claymation Style Rules

Use these rules to make the generated result feel like a handcrafted stop-motion film still instead of a generic 3D render or smooth plastic toy.

## Character Construction

- Use rounded clay volumes with slight asymmetry.
- Keep visible fingerprints, thumb marks, soft dents, and hand-smoothed seams.
- Let facial features be expressive but respectful: rounded nose, lively eyes, shaped brows, slightly oversized mouth when suitable.
- Preserve source-person cues through hairstyle silhouette, outfit color, posture, gaze, accessories, and expression.
- Clothing should look sculpted from soft clay or fabric-like clay sheets, not realistic cloth simulation.
- Hands may be slightly oversized and handmade, especially if they hold props.

## Miniature Set Construction

- Use cardboard walls, clay furniture, painted paper, fabric scraps, wire, small lamps, handmade signs without readable text, and toy-scale props.
- Add tiny imperfections: uneven edges, small tool marks, tilted objects, hand-cut paper, brushed paint texture.
- Keep the set coherent with the person's likely story or role.
- Avoid glossy CGI surfaces, perfect geometry, stock-photo realism, sterile studio backdrops, and generic fantasy decorations.

## Cinematic Image Rules

- Prefer film-still framing: close-up, medium shot, three-quarter view, low angle, overhead, or shallow depth of field.
- Use practical-looking miniature lighting: window glow, desk lamp, warm classroom light, dusk side light, night blue-purple fill.
- Keep the subject readable in the first glance.
- Let foreground and background props support the story without overcrowding the frame.
- Preserve a handmade stop-motion pause: the image should feel like a single frame from an animated scene.

## Prompt Fixes

If the output looks too realistic:

```text
more handcrafted clay texture, visible fingerprints, stop-motion puppet, miniature set, handmade props, slightly imperfect clay surface
```

If the output looks too plastic:

```text
matte clay, hand-smoothed fingerprints, tiny dents, non-glossy surface, soft handmade edges
```

If the person no longer resembles the source:

```text
preserve the source photo's hairstyle silhouette, face shape, posture, outfit colors, accessories, and expression
```

If the scene feels empty:

```text
add miniature handmade props that reflect the person's role and mood, cardboard set walls, clay table, handmade lamp, paper objects
```

If the image includes bad text:

```text
no readable text, no letters, no logo, no watermark, blank paper props only
```

## Default Medium Line

```text
Aardman claymation style, handcrafted miniature set, visible fingerprints, stop-motion aesthetic, cinematic film still, clay character, handmade props, shallow depth of field, matte clay texture, no text, no watermark.
```
